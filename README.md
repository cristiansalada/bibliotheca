# Bibliotheca 🏛️

**Bibliotheca** es una Progressive Web App (PWA) de un solo archivo, diseñada con una cuidada estética de biblioteca clásica (tonos pergamino, tipografía serif noble, contraste café oscuro) para la gestión integral de una biblioteca personal y lecturas.

---

## Características Principales

- **Estética Clásica & Elegante**: Interfaz cálida inspirada en bibliotecas tradicionales (`#faf6ee`, `#2d1e13`), botones sobrios monocromáticos y tipografía serif.
- **Escaneo Continuo de Códigos de Barras**: Compatible con la cámara trasera de cualquier móvil usando `html5-qrcode`. Permite escaneo masivo con señal acústica (beep de Web Audio API), destello visual y procesamiento por lotes enriqueciendo los datos mediante la API de Google Books y Open Library.
- **Búsqueda Asistida por Título / Autor**: Autocompletado inteligente para añadir ejemplares sin necesidad de escanear, permitiendo seleccionar entre las ediciones encontradas.
- **Calificación Interactiva**: Sistema de 1 a 5 estrellas táctil y editable para cada ejemplar.
- **Gestión de Estados de Lectura**: Transiciones fluidas entre *Wishlist (Lista de Deseos)*, *Sin leer (Pendiente)*, *Leyendo* y *Leído*.
- **Control de Préstamos**: Registro de a quién se le prestó cada ejemplar y generación de recordatorios directos por WhatsApp.
- **Estadísticas & Metas Anuales**: Contador de libros leídos en el año, en el mes, páginas acumuladas, horas estimadas de lectura, género favorito y barra de progreso hacia tu meta anual configurable.
- **Asistente Literario Integrado**: Compatible con Google Gemini API (REST) con análisis semántico de sinopsis para sugerencias y recomendaciones a medida.
- **Gestión de Datos (Archivo)**: Exportación e importación en formato JSON y exportación a planilla CSV (con UTF-8 BOM compatible con Microsoft Excel).

---

## Instalación como App (PWA)

1. Abre el enlace en tu navegador móvil (Safari en iOS, Chrome en Android):
   **[https://cristiansalada.github.io/bibliotheca/](https://cristiansalada.github.io/bibliotheca/)**
2. Pulsa en el menú del navegador y selecciona **"Añadir a la pantalla de inicio"** o **"Instalar aplicación"**.
3. ¡Listo! Se abrirá a pantalla completa como una aplicación nativa.
